# mucho - screenshot uploader
Tool for managing screenshots uploaded automatically. 

Name comes from the spanish word `mucho`, which means "a lot" or "many", because I have a bunch of screenshots.

## Developing

Once you've created a project and installed dependencies with `bun install`, start a development server:

```bash
bun run dev
```

## Building

To create a production version of your app:

```bash
bun run build
```

You can preview the production build with `bun run preview`.
